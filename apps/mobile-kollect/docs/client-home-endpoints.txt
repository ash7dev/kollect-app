Collections (public)
1) GET /collections/featured
   - Appel: collectionsApi.getFeatured(limit=6)
   - Query params: limit: number (par défaut 6)
   - Auth: Aucune
   - Réponse attendue: 200 OK
     Body: CollectionDto[]
     CollectionDto: {
       id: string,
       name: string,
       slug: string,
       description?: string | null,
       coverImage?: string | null,
       teaserVideo?: string | null,
       status: 'TEASER' | 'DISPONIBLE' | 'EPUISEE' | 'TERMINE',
       launchDate?: string | null,
       launchedAt?: string | null,
       isFeatured: boolean,
       brandId: string,
       viewCount: number,
       brand: { id: string, name: string, logo: string | null, slug: string } | null,
       _count: { views: number, products: number },
       createdAt: string,
       updatedAt: string,
       products?: ProductDto[]
     }
   - Notes: coverImage/teaserVideo/brand.logo peuvent être renvoyés en chemin relatif. Le client préfixe avec l’host si nécessaire.

2) GET /collections/trending
   - Appel: collectionsApi.getTrending(limit=6)
   - Query params: limit
   - Auth: Aucune
   - Réponse: 200 OK, Body: CollectionDto[]

3) GET /collections/new

4) GET /collections/coming-soon
   - Appel: collectionsApi.getComingSoon(limit=6)
   - Query params: limit
   - Auth: Aucune
   - Réponse: 200 OK, Body: CollectionDto[]

Gestion des erreurs (côté client)
- Si response.ok === false, les services lèvent une Error avec un message générique (ex: "Erreur chargement produits ...", "Erreur lors de la récupération").
- Le composant affiche une alerte et un message d’erreur utilisateur.

Ce que fait le client dans ClientHomeScreen
- Récupère en parallèle:
  - Collections: featured, trending, new, coming-soon
  - Produits: popular, new, puis featured
- Normalise les URLs médias des collections quand la réponse contient des chemins relatifs (préfixe avec https://.../).
- Stocke les résultats dans l’état pour un rendu ultérieur (seule la section collections en vedette et produits tendance est affichée pour l’instant).

Hypothèses serveur
- Toutes les routes listées ci-dessus sont publiques (pas d’en-tête Authorization requis) sauf les routes "personalized" (non utilisées ici).
- Les collections renvoient un tableau simple (CollectionDto[]).
- Les produits renvoient un objet paginé { data, meta }.
- Codes d’état attendus: 200 OK en cas de succès; en cas d’échec, un code 4xx/5xx et un body JSON { message?: string } si fourni.
